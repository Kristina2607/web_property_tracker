## Описание

Приложението позволява на потребителя да добавя URL адреси на обяви (имоти) и да следи автоматично тяхната цена, локация, площ или други стойности.  
При всяка проверка програмата извлича информацията от страницата и показва дали има промяна.

Поддържани сайтове:
- **imot.bg**
- **bazar.bg**

## Основни функционалности

### Управление на обекти
- Добавяне на обект за следене  
- Редактиране  
- Изтриване  
- Ръчно обновяване  
- Интервал на проверка  

Всеки обект съдържа:
- URL  
- сайт  
- критерий  
- интервал  

### Критерии за следене

Поддържани типове:

#### CSS selector
Пример: .

#### Keyword
Пример: €

#### Presets
Позволяват извличане без да се знаят CSS селектори:

preset:price
preset:location
preset:area
preset:psm
preset:title

## Автоматично събиране на данни

Програмата:
- проверява страниците периодично  
- извлича стойност  
- сравнява с предишната  
- показва статус  

Статуси:
- OK  
- Changed  
- error  

Използва се background thread, за да се гарантира, че GUI няма да блокира.
